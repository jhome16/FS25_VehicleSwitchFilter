# FS25_VehicleSwitchFilter

Vehicle Switcher Filter.        
A toggle to cycle thru vehicles with (engines running or AI controlled only) vs. default all vehicles, using default switching keys.
No need to change "switch vehicle" inputs.
If no vehicles are running or AI driven with toggle on, will still switch vehicles by default (with warning message shown).
Toggled on or off shows icon next to speedometer display.
Will exclude AI vehicles from mod- (FS25_WorkingNeighborOnField).

Toggle ON/OFF keys can be adjusted.
-Switch Thru Active  ("right Alt + keypad 7") ("BUTTON_5 BUTTON_6 BUTTON_11")
