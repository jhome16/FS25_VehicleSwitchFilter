# FS25_VehicleSwitchFilter

**Vehicle Switcher Filter** - cycle through only the vehicles that are in use, with the default switching keys.

- A toggle to cycle through vehicles with engines running or AI controlled only, instead of all vehicles.
- No need to change the "switch vehicle" inputs.
- If no vehicles are running or AI driven with the toggle on, vehicles are still switched by default (with a warning message shown).
- An icon next to the speedometer shows whether the toggle is on or off.
- Excludes AI vehicles from the mod FS25_WorkingNeighborOnField.
- Available in 11 languages: en, de, fr, es, it, pl, cz, ru, br, nl, tr.

## Keys

The toggle keys can be adjusted in the game's controls menu under "Switch Thru Active".

- Keyboard: right Alt + keypad 7
- Gamepad: BUTTON_5 BUTTON_6 BUTTON_11

## Download and install

1. Open the [latest release](https://github.com/jhome16/FS25_VehicleSwitchFilter/releases/latest) and download `FS25_VehicleSwitchFilter.zip`.
   Direct link: https://github.com/jhome16/FS25_VehicleSwitchFilter/releases/latest/download/FS25_VehicleSwitchFilter.zip
2. Put the zip file, without unzipping it, in your mods folder:
   - Windows: `Documents\My Games\FarmingSimulator2025\mods`
   - Mac: `~/Library/Application Support/FarmingSimulator2025/mods`
3. Start the game and enable the mod in your savegame.

Do not use "Code > Download ZIP" on this page. That zip has an extra folder level and the game will not load it.
